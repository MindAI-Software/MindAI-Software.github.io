## 2025-03-18 - [Metadata UX for Social Sharing]
**Learning:** Social media link previews are a critical part of the user experience when sharing content. Missing Open Graph and Twitter Card tags lead to uninformative previews that reduce click-through rates.
**Action:** Always include a core set of metadata (OG and Twitter) to ensure shared links are descriptive and visually appealing.

## 2025-03-18 - [Social Verification with rel="me"]
**Learning:** For developers and software organizations, verifying identity across platforms (like GitHub and Mastodon) is important for trust. Using `rel="me"` on outgoing social links enables automated federated verification.
**Action:** Include `rel="me"` on primary social and profile links to support cross-platform identity verification.
